# Portable Air Quality Monitoring System

Portable embedded environmental monitoring system designed for real-time air quality sensing, wireless data logging, airflow optimization, and portable environmental analysis.

This project combines:
- Embedded Systems
- Environmental Sensing
- Wireless Communication
- IoT Architecture
- Mechanical CAD Design
- Electronics Integration
- Portable Product Prototyping

The system was developed to monitor environmental air conditions while maintaining compact packaging, controlled airflow, wireless connectivity, and portable operation.

---

## Project Overview

The device integrates environmental sensing components, wireless communication, airflow management, and embedded firmware into a compact portable enclosure.

Sensor data is transmitted wirelessly and logged through an Apache webserver for remote monitoring and environmental analysis.

Key engineering goals included:
- portable operation,
- wireless telemetry,
- airflow optimization,
- sensor integration,
- enclosure development,
- and real-time environmental monitoring.

The project involved:
- CAD enclosure development,
- iterative mechanical prototyping,
- airflow analysis,
- embedded firmware development,
- wireless communication integration,
- webserver-based data logging,
- and hardware assembly.

## Wireless Monitoring Architecture

The system supports wireless environmental data transmission to an Apache webserver for remote monitoring and logging.

The wireless architecture enables:
- remote sensor monitoring,
- centralized data collection,
- real-time environmental analysis,
- and network-based accessibility.

The IoT communication pipeline includes:
1. Sensor acquisition
2. Embedded data processing
3. Wireless transmission
4. Apache webserver logging
5. Remote monitoring interface
