# Portable Air Quality Monitor — System Overview

## Project Objective

This project implements a portable environmental monitoring system capable of measuring indoor air quality parameters using integrated environmental sensors.

The system was designed to:
- monitor airborne pollutants,
- improve airflow management,
- provide portable sensing capabilities,
- and support environmental health analysis.

---

## Core Features

- Portable battery-powered operation
- Environmental sensing
- Active airflow system
- Sensor integration
- Custom enclosure design
- Embedded firmware control
- Real-time monitoring

---

## System Components

The system integrates:
- Environmental sensors
- Cooling fan
- Embedded controller
- Display interface
- Power subsystem
- Custom 3D-printed enclosure
